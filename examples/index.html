nu-pivottables Examples

nu-pivottables is a FOSS Javascript Pivot Table (aka Pivot Grid, Pivot Chart, Cross-Tab) implementation with drag'n'drop functionality written by Alireza Alavi, continuing and improving PivotTable.js by Nicolas Kruchten.

(Source code)

To see what it can do and how, browse the examples below or check out the documentation wiki for full details.
